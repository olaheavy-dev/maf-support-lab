# [E08] Post-build Microsoft evaluation and reporting

## Outcome

After the .NET and Python backends are built and verified, create shared evaluation datasets/runners, integrate native Microsoft evaluation APIs, and report deterministic and budgeted judge results.

## Exit criteria

Both targets run the same versioned behavior datasets; native .NET/Python evaluations are demonstrated; model-based scores are separated from business gates; reproducible reports and CI artifacts exist.
