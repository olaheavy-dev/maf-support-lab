## What I will implement

- [ ] Reorganise Support.Api into Common and Modules/<X> folders with Domain, Application, Infrastructure, and Presentation layers (namespaces follow folders); Program.cs only calls each module's Add/Map methods.
- [ ] Move use-case logic out of endpoints into one sealed command or query handler per use case returning Result/Error; endpoints and agent tools only translate input and output. Storage sits behind Application interfaces implemented in Infrastructure.
- [ ] Enforce the layering with ArchUnitNET rules (layer dependencies, handler and message shape, every type in a layer) and self-tests that run each rule over deliberately broken fixtures.
