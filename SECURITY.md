# Security

This is a learning repository using synthetic records and simulated business operations.
Never commit API keys, real customer records, session stores, checkpoint data, or captured prompts containing private information.

Use environment variables or the relevant runtime's local secret facilities. Keep examples as placeholders.
Do not put secrets or exploitable details into a public issue. For a suspected vulnerability, use GitHub private vulnerability reporting when enabled, or the repository's Security tab to find the available private reporting route.

Dependency alerts and automated updates support maintenance; they do not establish that a system is secure or production-ready.
